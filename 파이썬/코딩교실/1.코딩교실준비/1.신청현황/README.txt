Coding classroom application status auto-update package

Read this first:
- Main guide: README_매크로PC_설치및실행.md
- Run once: run_update_once.ps1
- Start 10-minute loop: start_auto_update.ps1
- Install startup task: install_startup_task.ps1
- Remove startup task: uninstall_startup_task.ps1

Important:
- This package contains local configuration files used by the status downloader.
- Do not share the package publicly.
- Google Sheets sync needs a Google service-account credential file at:
  _secrets\google_service_account.json

Prompt for Codex on the macro PC is included in README_매크로PC_설치및실행.md.
