동작 설명

1. 엑셀 A열의 강사/반 코드와 B열의 Zoom 링크를 읽습니다.

2. Q열 설정값으로 LMS 관리자 페이지에 로그인합니다.
   - Q1: 로그인 사이트 링크
   - Q2: 강사 관리 링크
   - Q3: admin ID
   - Q4: admin PW

3. 각 강사/반 코드를 검색한 뒤 상세 팝업의 video_link 입력칸에 Zoom 링크를 저장합니다.

4. 저장 후 같은 대상 전체를 다시 조회해서 LMS에 저장된 링크가 엑셀 링크와 정확히 같은지 검증합니다.


엑셀 작성법

- A1: 반 또는 강사ID
- B1: 링크
- A2:B2부터 실제 저장할 목록을 작성합니다.
- A열이 처음 비어 있는 행에서 목록을 종료합니다.
- 중간에 빈 A열이 있으면 아래 데이터는 처리하지 않습니다.
- 같은 Zoom 링크를 여러 반에서 공유할 수는 있지만, 실행 전 경고로 표시됩니다.


실행 방법

현재 폴더에서 아래 명령을 실행합니다.

python LMS줌링크.py


검증만 하고 LMS 값을 바꾸지 않으려면 아래 명령을 실행합니다.

python LMS줌링크.py --verify-only


엑셀 입력값만 검사하고 LMS에 접속하지 않으려면 아래 명령을 실행합니다.

python LMS줌링크.py --dry-run


중간부터 재시작하려면 시작 행을 지정합니다.

python LMS줌링크.py --start-row 15


로그

- 실행 결과는 logs 폴더에 CSV로 저장됩니다.
- status가 OK가 아닌 행은 LMS에서 재확인해야 합니다.
